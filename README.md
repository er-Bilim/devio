## Быстрый старт

Нужен только Docker.

```bash
git clone https://github.com/er-Bilim/devio.git && cd devio
cp backend/.env.example backend/.env    # вписать SECRET_KEY
docker compose up --build
```

Через минуту всё на месте:

| | |
|---|---|
| **Фронтенд** | http://localhost:3000 |
| **API + Swagger** | http://localhost:8000/docs |
| **PostgreSQL** | localhost:5432 – база `devio`, тестовая `devio_test` создаётся сама |

Миграции накатываются при старте. Порты привязаны к `127.0.0.1`.

<br>

## Режимы запуска

```bash
docker compose up                         # дев – bind mounts, hot-reload
docker compose -f docker-compose.yml up   # прод-репетиция – код запечён в образ
./dev.sh                                  # база и бэк в докере, фронт на хосте
```

<br>

## Тесты

```bash
cd backend && pytest -v
```

Интеграционные, против настоящего Postgres – auth-цикл целиком
(регистрация → логин → ротация refresh → отзыв → логаут), идемпотентность
завершения этапов, стрик на параметризованных сценариях дат.

Изоляция через savepoint-транзакции: каждый тест стартует с чистой базы.
CI гоняет тесты, линт и сборку фронта на каждый PR – красное не мержится.

<br>

## Как устроен код

```
backend/app/
├── routers/      HTTP-слой: принял → отдал, без SQL и логики
├── services/     сценарии: транзакции, составные операции
├── queries/      весь SQL проекта
├── models/       таблицы по доменам
├── schemas/      Pydantic-контракты
└── tests/        фикстурная лестница client → registered → auth

frontend/src/
├── app/          роуты Next: страницы только собирают виджеты
├── widgets/      блоки страниц
├── features/     действия пользователя
├── entities/     сущности: данные и их отображение
└── shared/       api-клиент, ui-кит, сгенерированные типы
```

Типы фронта генерируются из OpenAPI-схемы бэка командой `npm run gen:api` –
контракт один, руками не дублируется.

## Решения, которыми я доволен

**Auth.** JWT в httpOnly-куках: короткий access и refresh с ротацией.
Хеши refresh лежат в базе – украденный и использованный токен бесполезен.
Пароли на argon2.

**Статика вместо запросов.** Публичные страницы – роадмапы, направления,
описание – печатаются при сборке и раздаются готовыми. Бэк не просыпается,
пока контент не изменится: инвалидация по тегам через защищённую ручку.

**Два транспорта.** Серверные запросы разведены по сортам данных: публичное
идёт без кук и кешируется, личное – с куками и без кеша. Одна кука в общем
предке делает динамическим всё дерево, поэтому авторизация инициализируется
на клиенте.

**Стрик на SQL.** Дни подряд считаются одним запросом через оконные функции,
а не циклом в питоне.
